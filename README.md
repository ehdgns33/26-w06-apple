# 🍎 사과게임

사과 위에 적힌 숫자를 드래그로 이어 합이 10의 배수가 되면 사과를 수확하는 1분 게임입니다. 8×8 보드에서 가로·세로·대각선으로 연결할 수 있고, 선택한 숫자의 합만큼 점수를 얻습니다.

## 실행 방법

`index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다. 별도 설치나 빌드 과정은 필요하지 않습니다.

## 게임 구성

- 시작 버튼을 누르면 60초 라운드가 시작됩니다. 사과를 수확하면 위쪽 사과가 아래로 내려오고, 빈칸은 새 사과로 채워집니다.
- 새 최고 점수를 세우면 컨페티 효과가 나오며, 기록은 브라우저의 `localStorage`에 저장됩니다.
- Vanilla JavaScript로 보드 생성, 드래그 선택, 합계 판정, 점수 및 타이머를 구현했습니다. 페이지에는 하늘과 구름 테마를 적용했습니다.
- HTML, CSS, JavaScript를 각각 `index.html`, `style.css`, `script.js`로 분리했습니다.

자세한 실습 절차는 [guide.md](./guide.md)를 참고하세요.
