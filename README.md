# 🍎 사과게임

숫자가 적힌 사과를 드래그로 이어 수확하는 1분 퍼즐 게임입니다. 8×8 보드에서 합이 10의 배수가 되도록 숫자를 연결하고, 더 높은 점수에 도전해 보세요.

## 게임 방법

1. **게임 시작**을 눌러 60초 라운드를 시작합니다.
2. 마우스나 터치로 숫자 사과를 드래그해 연결합니다. 가로·세로·대각선으로 이웃한 사과만 이어지며, 한 사과를 두 번 선택할 수 없습니다.
3. 드래그를 놓았을 때 선택한 숫자의 합이 10의 배수면 수확에 성공합니다. 점수는 선택 숫자의 합만큼 올라갑니다.
4. 수확한 사과 위에 있던 사과들이 아래로 내려오고, 위쪽 빈칸은 새 사과로 채워집니다. 조건에 맞지 않으면 점수 없이 선택이 취소됩니다.
5. 시간이 끝나면 최종 점수를 확인하고 다시 도전할 수 있습니다.

## 주요 기능

- 최고 점수는 브라우저에 저장되어 다음 방문에도 유지됩니다.
- 최고 기록을 새로 세우면 컨페티 축하 효과가 나타납니다.
- 사과 낙하 애니메이션과 작은 화면에 맞춘 반응형 레이아웃을 적용했습니다.

## 실행 방법

저장소의 `index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다. 설치나 빌드 과정은 필요하지 않습니다.

## 기술 구성

- HTML: 게임 화면과 점수·타이머 UI
- CSS: 사과 보드, 애니메이션, 하늘 배경 및 반응형 디자인
- Vanilla JavaScript: 보드 생성, 드래그 판정, 수확·낙하, 점수 및 타이머
- `localStorage`: 최고 점수 저장

실습 절차는 [guide.md](./guide.md)를 참고하세요.
